# Personas

## Writer

- id: writer
- who: A person who keeps short notes in a terminal app, many times each day.
- jobs:
  - writer.J1: When I have an idea, I want to save it in one step, so that I do not lose it.
  - writer.J2: When I need an old note, I want to find it fast, so that I can use it again.
- limits:
  - device: laptop
  - skill: uses a terminal every day
  - access: own notes only
- evidence: assumed
