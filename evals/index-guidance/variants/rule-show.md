## Code index

- If `stone-index` is on PATH, ask the code index before you search or read code. To read a symbol, use `stone-index show <name>`, not a whole-file read.
- Use `stone-index find <name>`, `stone-index refs <path or module>`, `stone-index outline <path>`, or `stone-index search "<words>" --context 5`.
- Read a whole file only if `show` and `search --context` do not give the lines that you need.
